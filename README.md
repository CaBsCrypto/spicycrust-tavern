# 🍕 SpicyCrust Tavern

> **Portal de minijuegos arcade de pizza con cabinas 3D interactivas, integración Web3 y diseño de sonido retro.**

🎮 **Juega ahora:** [https://spicycrust.com](https://spicycrust.com)

---

## 🎰 Juegos Disponibles

| # | Juego | Descripción |
|---|-------|-------------|
| 1 | **Rhythm Slice** | Rebana ingredientes al ritmo de la música |
| 2 | **Slice Hunter** | Caza pizzas en modo aventura |
| 3 | **Slash Slice** | Corta ingredientes a velocidad máxima |
| 4 | **Spicy Challenge** | Desafío picante con grids de combinación |

## ⚡ Tech Stack

- **Frontend:** HTML5, JavaScript (ES Modules), Tailwind CSS v4
- **3D Engine:** Three.js — cabinas arcade interactivas con texturas procedurales
- **Audio:** Web Audio API — efectos retro sintetizados en tiempo real
- **Web3:** Reown AppKit + Ethers.js — conexión de wallets multi-chain
- **Build:** Vite
- **Deploy:** Vercel

## 🚀 Desarrollo Local

```bash
# Instalar dependencias
pnpm install

# Servidor de desarrollo
pnpm run dev

# Build de producción
pnpm run build
```
